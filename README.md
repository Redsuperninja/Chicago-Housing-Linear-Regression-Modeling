# Chicago Housing Price Modeling

Linear regression models predicting Cook County (Chicago) home sale prices, built for a CU Boulder data science course with Python, Pandas, NumPy and scikit-learn.

The work covers data cleaning, feature engineering (including one-hot encoding of categorical features), regularized regression (Lasso and Ridge), and evaluation with cross-validation, RMSE and residual analysis. It also discusses the fairness of property tax assessment: who gains when assessments run high or low, and the effect of systematically over- or under-valuing inexpensive homes.

`ProjPart2.pdf` is the exported write-up with code, plots and answers.
